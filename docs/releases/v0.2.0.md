# v0.2.0: RTX 4090 receipt scaling

The [v0.2.0 tag](https://github.com/Alberto-Codes/inference-lab/tree/v0.2.0) is public and immutable.
The companion post and GitHub prerelease are public, verified 2026-10-28.

See the [experiment index](../reference/experiments.md) for version provenance.

This experiment extends the receipt pilot with a manifest-driven open-loop runner,
bounded concurrency, durable checkpoints and offline scoring.
It preserves 9,228 measured outcomes and 955 separate warmup outcomes.
Coverage contains 56 CORD receipts; 20 evaluation receipts remain untouched.
The published `v0.1.0` baseline is unchanged.

Five offered pages/s kept queueing low for five minutes.
Six offered pages/s grew a queue and rejected work.
Each long condition ran once. These results do not establish zero-failure capacity.
At five pages/s, 26 requests timed out on the same receipt.
Verified digit changes and unrelated generation remain quality failures.

Check out `v0.2.0` before preparing the pinned corpus and reproducing the matrix:

```sh
uv run python scripts/scaling_suite.py \
  --input corpus/cord-scaling-56 --output runs/scaling-4090-matrix \
  --warmup-image corpus/page-01.png --release-llama
```

The service handover requires explicit operator authorization.
Follow the [historical procedure](https://github.com/Alberto-Codes/inference-lab/blob/v0.2.0/docs/how-to/run-scaling.md) for preparation, longer trials,
resume and offline rescoring of the retained raw evidence.
See the [results](../reference/scaling-results.md) and
[failure report](../reference/scaling-failures.md) for limits and the next experiment.
