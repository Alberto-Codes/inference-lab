# v0.1.0: Nemotron Parse receipt pilot

Status: [published prerelease](https://github.com/Alberto-Codes/inference-lab/releases/tag/v0.1.0), published 2026-10-27.

[Experiment index](../reference/experiments.md) · [Tagged code and evidence](https://github.com/Alberto-Codes/inference-lab/tree/v0.1.0)

This experiment runs Nemotron-3.5-Parse through vLLM on a local RTX 4090.
It preserves 24 CORD receipt inputs' provenance and 48 measured responses.
All measured requests completed. One amount changed from `79,500` to `79,300`.
Diagnostic ROUGE-L F1 was 0.801; exact numeric-string recall was 212/241.
The evaluation does not measure layout or table-structure accuracy.

Check out `v0.1.0` before recalculating the saved experiment without a GPU:

```sh
uv sync --locked
uv run python scripts/score_receipts.py \
  --input evidence/cord-test-24 --output runs/tag-inspection/scores.json
```
